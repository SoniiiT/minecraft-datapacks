# Sleep Vote

Datapack für Minecraft 26.3.

Sobald mindestens 50 % der Spieler in der Overworld schlafen (bei 2 Spielern reicht 1 Schläfer), startet ein 6-Sekunden-Countdown im Chat. Danach wird es Tag und der Regen/Gewitter hört auf. Steigt jemand vorher aus dem Bett und es sind zu wenige Schläfer, wird der Countdown abgebrochen. Spectator zählen nicht mit.

Installation: Ordner `sleep-vote` in `<welt>/datapacks/` kopieren, dann `/reload`.
