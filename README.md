# Minecraft Datapacks Repository

Willkommen in meinem Repository für selbst programmierte Minecraft-Datapacks! Hier findest du verschiedene Datapacks, die ich für Minecraft entwickelt habe.

## Was sind Datapacks?

Datapacks sind eine Möglichkeit, das Spielverhalten von Minecraft zu verändern, ohne den Spielcode direkt zu modifizieren. Sie ermöglichen es, neue Funktionen, Mechaniken und Inhalte hinzuzufügen, indem sie die bestehenden Spielmechaniken nutzen.

## Inhalt dieses Repositories

In diesem Repository findest du verschiedene Datapacks, die ich entwickelt habe. Jedes Datapack hat seinen eigenen Ordner mit einer detaillierten Beschreibung seiner Funktionen und Installation.

## Installation

Um ein Datapack zu installieren:
1. Lade das gewünschte Datapack herunter
2. Kopiere es in den `datapacks`-Ordner deiner Minecraft-Welt
3. Starte die Welt neu oder verwende den Befehl `/reload`
